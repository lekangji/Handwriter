Personalize

Teach the model how you write. Capture a few phrases, build a profile, and keep it for every new document.

  1. Capture samples. Open the sample capture tool (works with a mouse, but a stylus/tablet gives much better results). It starts with a one-time calibration stroke, then walks you through prompts — use its own text box to add your own phrases, especially punctuation the base model is weakest at. Click Download JSON when done.
  2. Upload it below and choose a name for this profile.
  3. Use it on the Write & Export page's profile dropdown once training finishes.

Older sample files are converted automatically for training. Files without calibration use an estimated writing scale.

Start with default when rebuilding a profile made before the capture fixes.

More epochs = closer fit to your samples, but slower and more prone to overfitting on small datasets.

Start small to preserve readable letters. Large values can erase what the model knows.

Runs in the background. Web training is capped to keep the workload reasonable (samples × epochs ≤ 800). For a bigger dataset, run python -m ai.training.finetune_cli from the command line instead — see README.md — which has no such limit.
